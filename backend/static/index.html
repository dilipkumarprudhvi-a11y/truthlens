    Verdict Categories
    
        
      
          
    • SUPPORTED — Retrieved evidence contains corroborating context with high relevance. Still requires human verification.
      • 
          
    • CONTRADICTED — Retrieved evidence contains explicit refutation signals (e.g., "fact-check rating: false", "debunked").
      • 
          
    • MIXED — Evidence contains both supporting and refuting signals across sources.
      • 
          
    • UNVERIFIED — No strong matching evidence found. This is not a verdict of falsity. Most recent or niche claims return UNVERIFIED because they are not yet in indexed knowledge bases.
      • 
        
    

        
    Evidence Sources
    
        
    TruthLens queries Wikipedia's OpenSearch API, DuckDuckGo's Instant Answer API, and (if configured) Google Fact Check Tools API. Evidence is only displayed when a real query returns a real result. No sources are fabricated.
    

        
    Linguistic Signals vs Factual Truth
    
        
    Clickbait score, sentiment, and bias indicators measure how text is written — not whether it is true. High sensationalism is a risk signal but not proof of falsehood. BREAKING NEWS headlines, negative coverage, and political reporting all contain high-signal words that are legitimate journalism.
    

        
    
          Important: TruthLens is a research and media literacy tool. Its verdicts should assist critical thinking, not replace it. Consult original primary sources for authoritative verification.
